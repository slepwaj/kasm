通字（Tungdzih / General Chinese）是赵元任《通字方案》的罗马字，用一套拼式写汉语的音类。

## 怎么打

- 每个字一个拼式，拼式本身带声调字母：`nii` 你、`xao` 好、`qoo` 我、`zao` 早。
- 连着打：`niixao` → 你好，`niixaoqoo` → 你好我，`uea` → 乌鸦。
- 词库里既有单字也有常用词；同一个输入串有多种切法时会一起查，按词频挑最像的。
- 词库以单字为主，多字词由整句拼起来；候选右侧显示它自己的通字读音。
- 也可以按 `'` 断开音节。

## 注意

- 通字码表来自 `baopaau/rime-tungdzih`，作者注明**大部分条目尚未校对**，不要当学习资料用。
- 通字与拼音 / 粤拼不能同时开；F4 预选栏的方案格按「拼 → 粤 → 通」循环。
