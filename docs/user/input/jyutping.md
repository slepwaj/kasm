---
title: 粤拼
order: 9
---

在设置 → 输入 → 拼音方案里选「粤拼（Jyutping）」，就可以用粤拼打粤语。

## 怎么打

- 不用写声调：`neihou` → 你好，`mgoi` → 唔該，`dimsyun` → 點算，`keoidei` → 佢哋。
- 音节之间可以直接连着打；想断开时用 `'`：`nei'hou`。
- 打到一半也有候选：`neih` 会按前缀给出「你好」这类词。
- 候选按词频和你的选择习惯排；常选的词会慢慢往前。

## 在拼音与粤拼之间切换

改设置里的「拼音方案」即可，**不用重启输入法**：配置一保存，输入法会自动把主词库换成另一套
（全拼用普通话词库、粤拼用粤语词库），下一键就按新方案出候选。切回全拼同样即时生效。

## 候选旁显示粤拼

每个候选右侧都显示它自己的粤拼，例如 `你好  nei hou`、`唔該  m goi`、`點算  dim syun`。
词库不带声调，所以显示的是**无调粤拼**，与敲法一致；整句候选也是整句的读音。

## 预选栏（F4）

按 **F4** 显示 / 收起桌面上的预选栏（悬浮状态条），上面从左到右是：

- 「中 / 英」：切中英文；
- 「拼 / 粤」：在拼音与粤拼之间切输入方案（主词库跟着换，不用重启）；
- 「简 / 繁」：简体 ↔ 上次用的繁体（同快捷键简繁切换）；
- 「，。」：切全角 / 半角标点（中英各记一份）；
- 「符」：打开符号面板；
- 齿轮：打开设置程序。

点一下即生效，设置会写回配置。F4 是输入法的功能键，Excel 之类用 F4 的应用里也会被输入法先接走。

## 需要注意

- 粤拼与拼音 / 双拼 / 五笔不能同时开。切到粤拼后，拼音方案里的模糊音、双拼、拼写纠错不生效；
  粤拼有自己的词图整句。
- 切换方案会自动换主词库，不用重启输入法进程。
- 粤语词库来自 CanCLID 的 Rime Cantonese 方案，按 CC BY 4.0 / ODbL 使用；出处与许可见「关于」页的数据来源。
