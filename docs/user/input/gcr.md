# 中文通用羅馬字输入方案

中文通用羅馬字（`çi`、`fəꝩ`、`jiæ`）是《古籍字頻統計》里的另一套标音，使用 `ç`、`ə`、`ꝩ`、`ɨ`、`ỵ`、`ę`、`ņ` 等字母。

## 怎么用

在 Android 键盘里选「中文通用羅馬字」键盘：

- 按 `ç` `i`，候选里会出现「之」；
- 空格或点候选上屏；
- 组合符 `̥ ̧ ̱` 的键面画在虚线圆圈上（`◌̥ ◌̧ ◌̱`），按下只送组合符；
- 倒数第二排左右两端是声调键，键面 `á` / `à`（字体没有单独的 `ˊ` / `ˋ` 字形）；按一下给当前音节加声调，再按另一个声调键会替换掉旧声调。GCR 词库把声调记在读音末尾的 `q` / `h`，所以键值对应 `q` / `h`；
- 底部 `ABC` 回到普通字母键盘。

## 词库来源

`古籍字頻統計_注音.xlsx` 的「中文通用羅馬字」列，多音字按 `/` 拆开；共 25,027 条字/读音（3,488 个音节；2026-11 修订版，声调用 q / h 记在读音里）。
