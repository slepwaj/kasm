上古音方案按《上古汉语》字表里的上古音拼写输入（Baxter–Sagart 式）。数据来自
`上古汉语.xlsx` 的「字典表」。

## 怎么打

- `pa` → 夫，`paq` → 补 / 父，`laj` → 移，`kra` → 家。
- 多音字每个读音都可以打，候选按字频排。
- 输入侧做了归一：去掉 `C.` 前缀，`'` 改写成 `x`，只留 `a`–`z`
  （`C.ra` → `ra`、`p'aq` → `pxaq`、`l'ik` → `lxik`）。

## 注意

- 词库是**单字表**：多字词由整句把单字拼起来。
- 与拼音 / 粤拼 / 通字 / tupa 不能同时开；F4 预选栏的方案格按「拼 → 粤 → 通 → tp → sg」循环。
